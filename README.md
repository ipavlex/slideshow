# TV Слайдшоу

Приложение-слайдшоу для Android TV (Xiaomi Mi Box и совместимые устройства).

Показывает фотографии из локальной папки с эффектами «Кен Бёрнс» и «Классика»,
управляется с пульта. Поддержка видео и Яндекс.Диск — в разработке.

## Возможности

- Выбор локальной папки через системный выбор (SAF / `ACTION_OPEN_DOCUMENT_TREE`)
- Два режима показа: **Ken Burns** (медленный pan+zoom) и **Классика** (статичное фото)
- Плавные кроссфейд-переходы между слайдами
- Циклическое воспроизведение, сортировка по имени
- Управление с пульта: перемотка, скорость, пауза

## Управление с пульта

| Кнопка | Действие |
|---|---|
| LEFT / RIGHT | Предыдущий / следующий слайд |
| UP / DOWN | Скорость (быстрее / медленнее) |
| OK (DPAD_CENTER) | Пауза / воспроизведение |
| BACK | Выход |

## Требования

- Android 9 (API 28) и выше
- Android TV / Google TV

## Сборка

### Android Studio

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. `Build → Build APK(s)` или запустите на устройстве.

### Командная строка

```bash
./gradlew assembleDebug      # отладочный APK
./gradlew assembleRelease    # release-APK (подписан debug-ключом для sideload)
```

APK: `app/build/outputs/apk/.../app-debug.apk` / `app-release.apk`.

Установка: скопировать APK на устройство (USB/флешка) и установить, либо
`adb install app-debug.apk`.

## Структура проекта

```
app/src/main/java/com/pzarubin/tvslideshow/
├── data/source/     # источники контента (SAF; Яндекс.Диск — позже)
├── domain/          # движок слайдшоу, режимы, плейлист
├── playback/        # KenBurnsView, SlideshowView, BitmapLoader
└── ui/              # MainActivity, SlideshowActivity
```
