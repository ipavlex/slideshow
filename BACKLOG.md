## Текущий спринт — баги и доработки (2026-10-10)

0. **Краш при выборе «Ken Burns» / «Классика»** — причина подтверждена: на устройстве нет
   системного SAF-пикера (`ActivityNotFoundException` при `ACTION_OPEN_DOCUMENT_TREE`).
   Решение: встроенный браузер папок (`FolderBrowserActivity`) + файловый источник
   (`FolderSource`) вместо SAF; разрешения `READ_EXTERNAL_STORAGE` (API ≤29) /
   `MANAGE_EXTERNAL_STORAGE` (API 30+). Статус: реализовано.

1. **Вынести выбор режима слайдшоу в настройки** — убрать кнопки режима с главного экрана.

2. **Кнопка «Выбрать локальную папку» на первом экране** — единая точка входа для локального слайдшоу.

3. **QR-код для авторизации Яндекс.Диска** — показать QR со ссылкой `verification_url`
   (зависимость zxing, `ImageView` на экране логина).

4. **Ошибка «wrong client secret»** — приложение зарегистрировано как «Веб-сервис» (confidential).
   Решение (вариант B, выбран): перерегистрировать на oauth.yandex.ru как public/нативное —
   device-flow без `client_secret`. Изменений кода не требует (код уже шлёт только `client_id`).

5. **Улучшить интерфейс** — фокус-подсветка, навигация D-pad, типографика, тёмная тема.

6. **Ступенчатая иконка/баннер** — растровые иконки (mdpi–xxxhdpi) + баннер 320×180,
   сглаженный play-треугольник, проверка safe-zone adaptive icon.

## Предложения по улучшению

**Приоритетные (в рамках MVP+):**
- Порядок: по имени / дате / случайно + перемешивание.
- Рекурсивный обход подпапок (галка).
- Несколько переходов: fade / slide / zoom / wipe (на выбор).
- Пре-загрузка соседних слайдов для плавности.
- EXIF-ориентация фото.
- Грациозный пропуск повреждённых файлов.
- Защита от выгорания экрана (смещение статичных элементов).

**Дальнейшие:**
- Фоновая музыка из той же папки (плейлист аудио параллельно).
- Сетка превью / браузер медиа перед запуском.
- Подписи: имя файла / дата / EXIF-метаданные.
- «Now Playing» карточка + seek-бар для видео.
- Режим «Screen Saver» / интеграция с ambient-режимом Android TV.
- Автоопределение USB-накопителей.
- Несколько сохранённых плейлистов, возобновление с места.
- Цифровые клавиши пульта → прыжок на слайд по номеру/проценту.

**Вне рамок (упомянуть, не планировать сейчас):**
- Видео-фон / анимированные переходы на GPU (OpenGL).
- Удалённое управление со смартфона (пульт-компаньон).
- Публикация в Google Play.

## Открытые вопросы

1. **Финальное имя приложения / пакет** (сейчас `com.pzarubin.tvslideshow`).
2. **Яндекс.Диск**: нужна ли рекурсия вложенных папок (там API-листинг постраничный)? Подтвердить приложение/`client_id` в Я.OAuth (значение лежит в `app/secrets.properties`).
3. **Кэш Я.Диск**: ограничение размера LRU (предлагаю 2 ГБ).
4. **HEIC** — сделано (0.9.0): нативный `libheif` + `libde265` собираются из вендоренных исходников
   через NDK/CMake (`app/src/main/cpp/`), фолбэк после системного `ImageDecoder`.
   Изыскания и план — [HEIC.md](HEIC.md). Осталось: проверить на устройстве (реальные HEIC).
