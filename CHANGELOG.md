# Changelog

Все значимые изменения проекта задокументированы здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Планируется
- Собственная релизная подпись (keystore).
- Плавный фейд видео (TextureView).
- Прекэш соседних слайдов.
- Защита от выгорания экрана.

## [0.7.3] — 2026-10-10

### Изменено
- Браузер папок: «Выбрать эту папку» первым пунктом списка; медиафайлы больше не забирают фокус при навигации.

## [0.7.2] — 2026-10-10

### Исправлено
- Проверка на пустые и битые файлы: пустые не попадают в плейлист/листинг, битые фото пропускаются.

## [0.7.1] — 2026-10-10

### Исправлено
- Скрытие служебных файлов macOS (`.DS_Store`, `._*`, `__MACOSX`) в слайдшоу и браузере.
- Сохранение пропорций фото (раньше могли растягиваться под экран).

## [0.7.0] — 2026-10-10

### Добавлено
- Встроенный браузер папок (внутренняя память + USB) вместо системного SAF-пикера.
- Редизайн TV-интерфейса: дизайн-токены, фокус-подсветка, типографика.

### Исправлено
- Краш при выборе локальной папки (нет SAF-пикера на Android TV).

## [0.6.0] — 2026-10-10

### Добавлено
- Кнопка «Выбрать локальную папку» на главном экране (единая точка входа).
- QR-код со ссылкой авторизации на экране входа в Яндекс.Диск.

### Изменено
- Режим слайдшоу (Ken Burns / Классика) вынесен в настройки.

### Исправлено
- Защита от краша при инициализации MediaSession в слайдшоу (try/catch).

## [0.5.1] — 2026-10-10

### Исправлено
- Краш при запуске: тема `Theme.Leanback` заменена на `Theme.AppCompat.NoActionBar`
  (AppCompatActivity требует тему из семейства AppCompat).

## [0.5.0] — 2026-10-09

### Добавлено
- Экран настроек: порядок, перемешивание, длительность фото, рекурсия подпапок.
- Рекурсивный обход подпапок в локальном источнике.
- R8 minify + shrinkResources для release (APK ~3.5 МБ).

## [0.4.0] — 2026-10-09

### Добавлено
- Источник Яндекс.Диск: OAuth device-code (`YandexAuth`, `YandexLoginActivity`).
- REST-клиент `YandexClient` + `YandexDiskSource` + файловый кэш `SlideCache`.
- Выбор папки на Диске (`YandexBrowseActivity`).
- Общий интерфейс `MediaSource` для локального и удалённого источника.

### Замечание
- `client_id` в `YandexConfig` — заглушка; заменить на реальный.

## [0.3.0] — 2026-10-09

### Добавлено
- OSD-оверлей: имя слайда, счётчик, скорость, индикатор паузы, прогресс видео.
- MediaSession (media3-session) — карточка Now Playing на Android TV.
- Метаданные видео (название файла) для Now Playing.

## [0.2.0] — 2026-10-09

### Добавлено
- Поддержка видео: Media3 ExoPlayer, `PlayerView` в `SlideshowView`.
- Смешанный плейлист фото+видео (`LocalFolderSource` распознаёт видео).
- Переходы фото↔видео; по завершении видео — переход к следующему слайду.
- Перемотка внутри видео (MEDIA_REWIND/FAST_FORWARD — seek ±10 с).
- Пауза/возобновление видео через состояние движка.
- Грациозный пропуск непроигрываемого видео (ошибка → следующий слайд).

## [0.1.0] — 2026-10-09

### Добавлено
- Каркас Android TV приложения (Kotlin, Leanback, minSdk 28, sideload-подпись).
- Выбор локальной папки через SAF (`ACTION_OPEN_DOCUMENT_TREE`) с персистентным разрешением.
- Листинг и фильтрация изображений (`LocalFolderSource`).
- Движок слайдшоу (`SlideshowEngine`): таймер, цикл, перемотка, скорость (0.25×–4×).
- Режимы показа: **Ken Burns** (`KenBurnsView`) и **Классика**.
- Кроссфейд-переходы между слайдами (`SlideshowView`).
- Управление с пульта: LEFT/RIGHT — слайды, UP/DOWN — скорость, OK — пауза, BACK — выход.
- Декодирование изображений через `ImageDecoder` (EXIF, защита от OOM).
- План проекта (`PLAN.md`).
